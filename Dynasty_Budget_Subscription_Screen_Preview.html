App lock with PIN

Set a PIN to require unlocking the app when it is opened. This is a privacy barrier, not encryption: browser-stored records are not encrypted by this feature. Keep your device locked and back up your data.

Fingerprint / biometrics

Use your device fingerprint, Face ID, or Windows Hello to unlock instead of typing the PIN. Your biometric data never leaves this device. Requires a modern browser and a secure context (HTTPS or localhost).

Backup health

For reliable recovery, save backup files somewhere outside this phone, such as a computer or secure cloud drive. Local browser storage can be lost if browser data is cleared.
